Runtime compatibility payloads owned by the TeknoParrot Winlator integration.
The x86 WinSCard stub is built from `WinlatorFork/native/teknoparrot-winscard-stub`.

`ffdshow-x86` contains the minimal 32-bit ffdshow tryouts rev4532 VfW runtime
used for title-scoped Indeo 5 playback. See `ffdshow-x86/SOURCE.txt` and
`ffdshow-x86/COPYING` for source and license information.
